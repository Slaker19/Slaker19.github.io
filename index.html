PROYECTO PRINCIPAL

WebKVM — Gestor de VMs nativo con UI web

Gestor de máquinas virtuales sobre libvirt + QEMU/KVM. Un solo binario Go con el frontend Svelte embebido: sin Docker, sin reverse proxy obligatorio, sin base de datos externa.

  • Instalador one-liner multi-distro: Debian/Ubuntu, Fedora/RHEL y Arch
  • HTTPS directo del backend con cert autofirmado (SAN IP + dominio)
  • Redes NAT y bridge macvlan, snapshots, backups programados
  • RBAC de 3 niveles, auditoría JSONL y CodeQL limpio
  • ~14 MB de binario · ~7 MB de RAM en reposo

Hardware: elegido para este trabajo

CPU · AMD Ryzen 7 5700U (8C/16T)

Los 16 hilos permiten levantar en paralelo los tres bancos de prueba de WebKVM (Ubuntu 8 GB + Fedora 4 GB + Arch 8 GB) sin que las 14 máquinas LXC se resientan. Y para un equipo que no se apaga nunca: su TDP de 15 W mantiene el nodo por debajo del consumo de una bombilla, con rendimiento sostenido multi-núcleo durante compilaciones Go y builds del frontend.

RAM · 32 GB

No es un número redondo al azar: las tres VMs de prueba suman 20 GB asignados; el resto da holgura a los contenedores LXC y alimenta la caché Btrfs del NVMe, de modo que compilaciones y health-checks nunca tocan swap. El punto justo entre «se queda corto al segundo test» y «pagar por RAM que duerme».

Servicios autoalojados (LXC)

Catorce contenedores LXC ligeros mantienen la casa funcionando: DNS, almacenamiento de credenciales, fotos, multimedia y utilidades varias. Delante, un Nginx Proxy Manager expone los servicios con hosts proxidados y certificados Let's Encrypt emitidos mediante desafío DNS sobre la API de Cloudflare.

Cómo trabajo

Nada se instala a mano dos veces: pruebo en VMs efímeras antes de tocar nada real, las instalaciones son reproducibles con un solo comando y cada despliegue acaba con validación automática de salud. Lo simple que funciona gana — binarios únicos, configuración persistente y cero magia oculta.
